# Leon Xu

我做 AI Agent、自动化工具和产品原型。比较喜欢从一个真实岗位或流程开始拆：这件事现在谁在做、每周花多少时间、哪里容易漏、哪里反复返工，然后先做一小段能跑的小试点。

现在主要看这几类场景：

- 客服 / 交付：工单、未解决问题、人工接管、复盘
- 运营 / 增长：用户反馈、内容和活动效果、下一步动作
- 销售 / 售前：客户资料、报价或招标样例、方案沉淀
- 内部流程：数据整理、表格、跨平台协作、重复汇报

一些公开项目：

- wakeupagent: privacy-first AI supervisor powered by LangGraph
- piggy-voice-agent: Telegram + TTS voice agent
- Minecraft_player / Minecraft_RL: Minecraft automation and RL experiments
- RLCFD: reinforcement-learning CFD framework work

如果你有一块工作已经在花钱招人，或者团队每周都在重复处理，我通常会先选一个小切口，7 到 10 天做成可验证的试点。
